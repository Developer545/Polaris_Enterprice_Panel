⚠️ PostgreSQL no está instalado o no está iniciado.
Polaris necesita PostgreSQL para almacenar todos los datos de tu empresa.
Sigue estos pasos:
  1. Descarga e instala PostgreSQL (el motor de base de datos)
  2. Durante la instalación, anota bien la contraseña del usuario postgres
  3. Descarga pgAdmin 4 (opcional pero útil para gestionar la base de datos)
  4. Reinicia esta pantalla con el botón "↺ Reintentar"
